# 우리들의 3년 — SEL 스토리 게임 프로토타입

## 실행
압축을 푼 뒤 `index.html`을 브라우저에서 열면 플레이할 수 있습니다. 현재는 별도 설치나 서버 없이 실행되는 1인 체험판입니다.

## 파일 구성
- `index.html`: 기본 구조 및 외부 리소스 연결
- `style.css`: 반응형 레이아웃과 스크롤형 스토리 UI
- `js/data.js`: 플레이어블 캐릭터, 스탯명, 36개월 이벤트·선택지 데이터
- `js/game.js`: 진행, 선택지 셔플, 타이머, 스탯 반영, 엔딩
- `js/ui.js`: 화면 렌더링, 스크롤 로그, 버튼·타이머 UI
- `js/sync.js`: 서버 연결 경계 모듈(현재 미연결)

## 프로토타입 범위
- 캐릭터 6종, 사용자 이름 입력, 랜덤 초기 스탯
- 36개월 진행, 선택 후 스토리가 아래로 누적되는 스크롤 UI
- 선택지 무작위 배열, 일반 35초·중요 55초·돌발 25초 타이머
- 스탯 조건에 따른 선택지 잠금/해금 및 스탯 변화
- 학교폭력 장면은 피해자에게 책임을 돌리지 않고, 어른에게 알리고 안전하게 지원하는 선택을 포함
- 실제 4인 온라인 동기화, 비밀 투표 집계, 교사용 화면은 서버 API 명세가 제공되지 않아 아직 구현하지 않음

## 수정 지점
- 이야기와 선택지는 `js/data.js`
- 타이머·스탯·진행 규칙은 `js/game.js`
- 화면·스크롤·버튼은 `js/ui.js`와 `style.css`

## 주의
이 빌드는 프로토타입입니다. 문장, 스탯 밸런스, 조건부 선택, 스트레스 페널티와 엔딩 규칙을 수업 적용 전에 검토하고 조정해야 합니다.
